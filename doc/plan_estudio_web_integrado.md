# Plan de Estudio: Desarrollo Web Integrado (2025 - Ciclo 2)

Este plan de estudio está estructurado con base en el sílabo del curso "Desarrollo Web Integrado" para prepararte progresivamente desde los conceptos básicos de back-end hasta la integración y despliegue final.

> [!TIP]
> Recuerda que el curso se evalúa mediante entregas parciales (**Avance de Proyecto Final** en las semanas 5, 10 y 15) y una entrega final en la semana 18. Organiza tu tiempo enfocándote en estos entregables.

## Unidad 1: API REST con Spring Boot (Semanas 1 - 5)
**Objetivo:** Implementar una API RESTful de back-end utilizando Spring Boot y aplicando TDD (desarrollo guiado por pruebas).

*   **Semana 1:** Introducción a Spring Boot. Configuración del entorno de desarrollo.
*   **Semana 2:** Configuración de endpoints, controladores y Dependency Injection.
*   **Semana 3:** Test-driven development (TDD) y su integración en Spring.
*   **Semana 4:** Implementación de API REST, uso de métodos HTTP y herramientas de prueba.
*   **Semana 5:** Integración de los temas vistos. 
    > [!IMPORTANT]
    > **Evaluación:** Avance de Proyecto Final 1.

## Unidad 2: Back-end con Bases de Datos (Semanas 6 - 10)
**Objetivo:** Conectar la aplicación Spring Boot a una base de datos relacional y aplicar políticas de seguridad.

*   **Semana 6:** Manejo de datos con JPA / Hibernate. Operaciones CRUD.
*   **Semana 7:** JPQL y transacciones en Spring Boot.
*   **Semana 8:** Seguridad con Spring Security. Configuración de roles y permisos.
*   **Semana 9:** Implementación de autenticación con JWT (JSON Web Tokens).
*   **Semana 10:** Integración de la capa de seguridad y datos.
    > [!IMPORTANT]
    > **Evaluación:** Avance de Proyecto Final 2.

## Unidad 3: Integración Back-end y Front-end (Semanas 11 - 18)
**Objetivo:** Integrar un proyecto back-end (REST) con un front-end (Angular) y desplegarlo en la nube.

*   **Semana 11:** Fundamentos de Angular. Componentes y estilos con SASS.
*   **Semana 12:** Rutas en Angular y comunicación entre componentes.
*   **Semana 13:** Formularios, validación de datos y manejo de errores.
*   **Semana 14:** Consumo de APIs REST. Autorización y autenticación en Angular.
*   **Semana 15:** Integración completa de temas (Back-end + Front-end).
    > [!IMPORTANT]
    > **Evaluación:** Avance de Proyecto Final 3.
*   **Semana 16:** Resolución de problemas comunes de integración entre frontend y backend.
*   **Semana 17:** Despliegue de aplicaciones web. Servidores y servicios cloud.
*   **Semana 18:** 
    > [!IMPORTANT]
    > **Evaluación:** Presentación del Proyecto Final.

---

### Estrategia Recomendada
1. **Practicar antes de cada entrega:** Aprovecha las semanas 4, 9 y 14 para pulir el código antes de los entregables importantes.
2. **Construir de forma iterativa:** El proyecto final se construye paso a paso. No dejes todo para la unidad 3; un back-end sólido en las Unidades 1 y 2 te ahorrará problemas de integración.
3. **Investigación continua:** Mantén la curiosidad sobre la documentación oficial de **Spring Boot** y **Angular**, ya que las mejores prácticas se actualizan frecuentemente.
